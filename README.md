# Gestor de Tareas
Aplicación hecha con Vue 3 para gestionar una lista de tareas.
Todo el código está en un único componente: `src/components/TaskApp.vue`.

## Cómo ejecutarlo
   ```
   npm install
   ```
   ```
   npm run dev
   ```
   Abrir en el navegador el enlace que sale en la terminal (http://localhost:5173).
